### v2: 운동 흐름 다시 설계 (2026-10-14)

v1 피드백: "헬스 운동은 종류가 워낙 많은데, Planfit 앱을 참고해서 비효율적인 목업을 수정해 달라."

v1의 운동 화면은 운동 4개를 버튼으로 나열하고 "+ 운동 추가"만 있어서, 운동 종류가 많아지면 고르기도 기록하기도 느립니다. Planfit 앱스토어 소개(루틴 추천·직접 만든 루틴, 무게·횟수·세트 기록, 운동 일지·캘린더, 헬스장 기구 기준 추천)와 운동 기록 앱들의 공통 화면 구조를 참고해 아래처럼 바꿨습니다. 앱 내부를 직접 열어 본 것은 아닙니다.

| 바꾼 점 | v1 | v2 |
|---|---|---|
| 운동 시작 | 빈 기록 화면 | **내 루틴으로 시작**(다음 차례 표시), 지난 운동 그대로, 운동 골라서 시작 |
| 운동 고르기 | 운동 4개 버튼 | **검색 + 부위 탭(가슴·등·하체·어깨·팔·복근·유산소) + 기구 필터(바벨·덤벨·머신·케이블·맨몸)**, 최근 한 운동, 여러 개 한 번에 고르기, 새 운동 만들기 |
| 세트 기록 | 무게·횟수 칸 | 세트마다 **지난번 값 옆에 표시 + 칸에 미리 채움**, 세트 +/−, 운동 메뉴(순서 바꾸기·바꾸기·빼기) |
| 루틴 | 없음 | **루틴 편집**: 이름, 운동 순서, 운동별 세트 수. 무게·횟수는 지난번 값을 씀 |
| 운동별 기록 | 운동 화면 안 | 별도 화면(최근 5회 흐름)으로 분리 |
| 오늘 화면 | 버튼 2개 | "운동 기록하기" 하나 + 다음 차례 루틴 표시 |
| 설정 | 운동 목록 | 내 루틴, 운동 목록(기본 운동 + 내가 만든 운동, 숨기기) |

- 기본 운동 목록은 직접 만든 목록(자주 쓰는 헬스 운동 100여 개 예정)을 씁니다. 다른 앱의 운동 데이터를 그대로 가져오지 않습니다.
- 데이터 표 추가(4차 문서 2-1): `routines`, `routine_items`, `exercises`에 부위·기구·직접 만든 운동·숨기기 칸.

### v2 화면 목록

| 화면 | 담은 것 |
|---|---|
| 운동 홈 | 내 루틴 3개(다음 차례 강조), 지난 운동 그대로 / 운동 골라서 시작, 최근 운동, 운동별 기록 보기 |
| 운동 고르기 | 검색, 부위 탭, 기구 필터, 최근 한 운동, 전체 목록(마지막 기록 표시), 여러 개 고르기, 새 운동 만들기 |
| 운동 기록 | 루틴에서 불러온 운동 카드, 세트별 지난번·kg·회, 세트 +/−, 운동·러닝 추가, 메모, 운동 후 컨디션, 체중(선택), 저장 |
| 운동별 기록 | 지난번 기록, 최근 5회 볼륨 막대와 세트 목록 |
| 루틴 편집 | 루틴 고르기, 이름, 운동 순서 위/아래, 세트 수 +/−, 빼기, 운동 추가 |
| 오늘·달력·식단·몸 변화·설정 | v1과 같음 (오늘의 운동 칸, 설정의 운동 항목만 수정) |

### v1 화면 목록

| 화면 | 담은 것 | 3차 설계 근거 |
|---|---|---|
| 오늘 | 날짜(누르면 달력), 이번 주 KPI(운동 횟수·식사 사진·인바디 판정), 오늘 루틴 체크리스트 | 2장 오늘, 3-1 |
| 달력 | 월 달력(월요일 시작), 날짜별 완료/놓친 항목 있음/기록 없음/오늘 표시, 고른 날의 빠진 항목과 채우기 | 2장 달력, 3-5 |
| 운동 (운동 전) | 운동 고르기, 지난번 기록, 최근 5회 흐름(막대 + 세트 목록), 기록하기 | 2장 운동(전), 3-2 |
| 운동 기록 (운동 후) | 지난번 값으로 채운 세트·무게·횟수, 세트·운동·러닝 추가, 메모, 운동 후 컨디션 1~5, 체중(선택), 저장 | 2장 운동(후), 3-2 |
| 식단 | 끼니별 상태(확인함 / 확인 필요 / 분석 실패 / 미기록), 확인함 버튼, 실패 시 직접 입력 | 2장 식단, 3-3 |
| 몸 변화 | 기간(1·3·6개월, 기본 1개월), 인바디 4개 수치와 좋음/주의, 체중 추이, 컨디션 추이 | 2장 몸 변화, 3-4 |
| 설정 | 운동 목록, 영양제·보충제 9종, 알림 2개, 엑셀 기간 내려받기, 구글 계정 | 2장 설정 |

### 목업에서 새로 제안한 것 (검수 필요)

1~4차 문서에 없던 것을 목업에서 처음 정한 부분입니다.

| 번호 | 제안 | 이유 | 상태 |
|---|---|---|---|
| P1 | 운동 기록 화면 맨 아래에 **체중 입력 칸(선택)** | 체중을 운동 직후에 재기 때문 | 검수 대기 |
| P2 | 식단 화면 맨 위에 **오늘 합계(확인한 끼니의 칼로리·단백질)** | 하루 식단을 한 줄로 보기 위해 | 검수 대기 |
| P3 | 영양제는 **하나씩 눌러 체크** (모두 먹음 버튼 없음) | 2차에서 항목별 체크로 정함 | 검수 대기 |
| P4 | 간식 칸은 **선택** (루틴 완료 조건에 넣지 않음) | 2차 완료 조건이 식사 3끼 | 검수 대기 |
| P5 | 운동별 기록은 **볼륨 막대 + 세트 목록**, 러닝은 거리 | 3차 "최근 5회 흐름" | 검수 대기 |
| P6 | **루틴**과 **다음 차례** (적어 둔 순서대로 돌아감) | 운동 종류가 많아도 시작을 빠르게 | v2 검수 대기 |
| P7 | 운동 기록 중 **완료 체크 칸은 두지 않음** | 운동이 끝난 뒤 한 번에 적기 때문 (1차 결정) | v2 검수 대기 |
