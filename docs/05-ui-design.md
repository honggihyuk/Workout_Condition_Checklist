## 1. 프레임 목업

색과 글꼴을 빼고 **화면 구성과 흐름만** 보는 회색 목업입니다. 색·글꼴·아이콘은 3단계 테마 선택에서 정합니다.

- 목업 링크: https://claude.ai/artifact/X6dB4EtbWY27tNTiaC6rWK
- 원본 파일: [docs/mockups/frame-v1/](./mockups/frame-v1/)
- 크기: 아이폰 화면 너비 390px 기준
- 아래 탭과 버튼을 누르면 화면끼리 이동합니다 (Play로 보기).

### 화면 목록 (v1)

| 화면 | 담은 것 | 3차 설계 근거 |
|---|---|---|
| 오늘 | 날짜(누르면 달력), 이번 주 KPI(운동 횟수·식사 사진·인바디 판정), 오늘 루틴 체크리스트 | 2장 오늘, 3-1 |
| 달력 | 월 달력(월요일 시작), 날짜별 완료/놓친 항목 있음/기록 없음/오늘 표시, 고른 날의 빠진 항목과 채우기 | 2장 달력, 3-5 |
| 운동 (운동 전) | 운동 고르기, 지난번 기록, 최근 5회 흐름(막대 + 세트 목록), 기록하기 | 2장 운동(전), 3-2 |
| 운동 기록 (운동 후) | 지난번 값으로 채운 세트·무게·횟수, 세트·운동·러닝 추가, 메모, 운동 후 컨디션 1~5, 체중(선택), 저장 | 2장 운동(후), 3-2 |
| 식단 | 끼니별 상태(확인함 / 확인 필요 / 분석 실패 / 미기록), 확인함 버튼, 실패 시 직접 입력 | 2장 식단, 3-3 |
| 몸 변화 | 기간(1·3·6개월, 기본 1개월), 인바디 4개 수치와 좋음/주의, 체중 추이, 컨디션 추이 | 2장 몸 변화, 3-4 |
| 설정 | 운동 목록, 영양제·보충제 9종, 알림 2개, 엑셀 기간 내려받기, 구글 계정 | 2장 설정 |

### 목업에서 새로 제안한 것 (검수 필요)

1~4차 문서에 없던 것을 목업에서 처음 정한 부분입니다.

| 번호 | 제안 | 이유 |
|---|---|---|
| P1 | 운동 기록 화면 맨 아래에 **체중 입력 칸(선택)** | 체중을 운동 직후에 재기 때문 |
| P2 | 식단 화면 맨 위에 **오늘 합계(확인한 끼니의 칼로리·단백질)** | 하루 식단을 한 줄로 보기 위해 |
| P3 | 영양제는 **하나씩 눌러 체크** (모두 먹음 버튼 없음) | 2차에서 항목별 체크로 정함 |
| P4 | 간식 칸은 **선택** (루틴 완료 조건에 넣지 않음) | 2차 완료 조건이 식사 3끼 |
| P5 | 운동 전 비교는 **볼륨 막대 + 세트 목록**, 러닝은 거리 막대 + 거리·시간·페이스 | 3차 "최근 5회 흐름" |

## 2. UI 의사결정

프레임 목업 검수가 끝나면 진행합니다. 버튼 위치, 입력 방식, 표시 방식 등 화면 규칙을 정합니다.

## 3. 테마 선택

UI 의사결정이 끝나면 진행합니다. 색, 글꼴, 아이콘, 밝은/어두운 화면을 정합니다.
